# Скажи — застосунок альтернативної комунікації

Мобільний застосунок для дітей з комунікативними порушеннями: дитина натискає піктограми,
застосунок озвучує слово або речення («Я хочу м'ячик»). Розроблено в межах магістерського
дослідження А. Полянської (Центр розвитку дитини Пресвятої Богородиці, м. Ужгород).

## Можливості
- три рівні, що відповідають етапам PECS: одна картка → «Я хочу» + картка → речення з категоріями;
- базовий набір із 10 карток (потреби, заохочення, дії) + постійні «Так / Ні / Стоп»;
- персональні картки з фото (камера або галерея), власний текст для озвучення;
- режим дорослого за PIN (за замовчуванням 1234): рівень, видимість і порядок карток, розмір, голос;
- журнал натискань зі статистикою за день/тиждень/місяць та експортом CSV (для моніторингу);
- працює без інтернету; усі дані лише на пристрої.

## Встановлення на Android (без Play Market)
1. Відкрийте сторінку **Releases** цього репозиторію і завантажте файл `Skazhy-vN.apk`.
2. На телефоні відкрийте завантажений файл → дозвольте встановлення з цього джерела → «Встановити».
3. Для українського голосу: *Налаштування → Система → Мова та введення → Синтез мовлення →
   Google Text-to-Speech → Установити голосові дані → Українська*.

Оновлення встановлюються поверх попередньої версії (один ключ підпису), дані зберігаються.

## Веб-версія
Тека `www/` — це звичайний вебзастосунок (PWA). Його можна відкрити в браузері або додати на
головний екран (Android Chrome, iPhone Safari → «На початковий екран»).

## Збирання
APK збирається автоматично GitHub Actions після кожного push у `main`
(`.github/workflows/build-apk.yml`). Локально: `npm ci && npx cap sync android && cd android && ./gradlew assembleRelease`.
